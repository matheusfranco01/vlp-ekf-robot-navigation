# requirements.txt — non-ROS Python dependencies for vlp-ekf-robot-navigation
#
# Scope: only packages that must be installed via pip. ROS-provided Python
# packages (rospy, rospkg, rostest, message_filters, tf) come from the ROS
# Noetic apt installation / your catkin workspace and are intentionally NOT
# listed here — pip-installing them would conflict with the ROS environment.
#
# Versions below are pinned to the last releases that ship official Linux
# wheels for BOTH Python 3.8 (ROS Noetic's official target, Ubuntu 20.04)
# and Python 3.10 (Ubuntu 22.04 / WSL2, your current environment per the
# screenshots). This was checked against PyPI's release metadata, not
# assumed.
#
# [EVIDENCE NEEDED] These versions have not been installed and exercised
# end-to-end against this repository's code in your actual ROS Noetic
# container. Before treating this file as final, run:
#   pip install -r requirements.txt --break-system-packages
#   roslaunch nav localization.launch
# and confirm ann.py loads models/model_RNA.pickle and produces /ann_pose
# without error. If you need to change a version to fix a conflict with
# an apt-installed package (python3-numpy, python3-scipy, python3-matplotlib
# are commonly preinstalled system-wide on ROS Noetic images), re-pin here
# and note why, so the next person does not have to rediscover it.

# --- vlp/scripts/vlp.py, estimator/*.py: signal generation and math ---
